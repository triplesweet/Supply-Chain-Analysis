# Supply-Chain-Analysis

**Business Need?**
> A Supply Manager needs a multi use dashboard that can simplify performance for executive reporting and be used daily for inventory analysis. Interactive Tableau Dashboard can be found here.

> Note: This excercise is based on a generated data set. Any business insights found should not be applied to any external market or industry.

**Business Questions?**
> Which SKU codes are low in stock?

> Can we meet the order amount with/without pending stock?

> What categories are performing best?

> What demographics are the most profitable?

> How much will revenue will be made in the future based on current lead generation?

> Which product catalog should be expanded? What price is the best for this new SKU code?

> What products should be discontinued?
